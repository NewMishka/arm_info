# arm_info

`arm_info` — Bash-скрипт для комплексной диагностики технического состояния АРМ под управлением РЕД ОС 7/8 и совместимых Linux-систем.

Скрипт собирает сведения об оборудовании и ОС, выполняет набор аппаратных и системных проверок, формирует сводный индекс текущего технического состояния, понятное заключение и рекомендации в формате «проблема → влияние → действие → команда». Результат одновременно выводится в терминал и сохраняется в TXT-отчёт.

## Что проверяется

- система: ОС, ядро, архитектура, модель ПК, BIOS, uptime, ориентировочная дата установки ОС;
- CPU: модель, сокеты, физические ядра, потоки, Load Average, температура по нескольким замерам;
- ОЗУ: тип, частота, число установленных модулей, доступная память, swap, события OOM;
- сеть: активные IPv4-интерфейсы, IP/MAC, скорость/duplex, шлюз, DNS, RX/TX errors и dropped, доля ошибок в ppm;
- накопители: HDD/SSD/NVMe/CD/DVD, модель, SMART, остаточный ресурс SSD/NVMe, температура, Power-On Hours, критические SMART-показатели;
- файловые системы: занятое место, inode, read-only, наиболее заполненный локальный раздел;
- стабильность ОС: failed systemd units, ошибки ядра/накопителей, уникальные ошибки journal текущей загрузки;
- эксплуатационный ориентир: возраст текущей установки ОС и максимальная наработка накопителя.

## Итоговая оценка

Индекс отражает **текущее техническое состояние**, а не прогноз срока службы. Вес групп:

| Группа | Вес |
|---|---:|
| Накопители / износ | 40% |
| Файловые системы | 15% |
| Стабильность ОС | 15% |
| Оперативная память | 10% |
| Процессор / температура | 10% |
| Возраст / наработка | 5% |
| Сеть | 5% |

Если достоверные данные группы недоступны (например, SMART), она не подменяется оценкой 100/100: группа исключается из расчёта, а показатель «Полнота проверки» снижается.

Подробная логика: [docs/SCORING.md](docs/SCORING.md).

## Требования

Минимально:

```bash
bash
iproute
util-linux
procps-ng
coreutils
```

Для полной диагностики рекомендуется:

```bash
dnf install smartmontools dmidecode lm_sensors
```

`smartmontools` особенно важен: без `smartctl` нельзя полноценно оценить состояние и износ накопителей.

## Запуск

Рекомендуется запуск от `root`:

```bash
bash arm_info.sh
```

Скрипт также специально пригоден для удалённой диагностики: его содержимое можно целиком скопировать и вставить в Bash-терминал после `su -`.

Запуск через `sh arm_info.sh` не рекомендуется, так как используются Bash-конструкции.

## Отчёт

TXT создаётся в текущем каталоге, а если он недоступен для записи — в `/tmp`:

```text
ARM_INFO_<hostname>_YYYY-MM-DD_HH-MM-SS.txt
```

Пример:

```text
ARM_INFO_arm-001_2026-09-15_14-20-00.txt
```

Отчёт содержит технические параметры, сводку состояния, ключевые показатели, заключение и рекомендации.

## Интерпретация рекомендаций

Каждая рекомендация содержит:

```text
[УРОВЕНЬ] Что обнаружено
Влияние:  на что влияет проблема
Действие: что сделать для устранения
Команда:  команда для проверки/диагностики
```

Уровни: `КРИТИЧНО`, `ВНИМАНИЕ`, `ПРОВЕРКА`, `ПЛАНОВО`.

## Ограничения

- дата установки ОС является ориентиром, а не датой производства ПК;
- дата BIOS выводится справочно и не используется как прямой возраст оборудования;
- SMART-атрибуты SATA SSD могут отличаться у разных производителей;
- температура CPU зависит от поддержки аппаратных датчиков ядром/драйвером;
- высокая занятость swap сама по себе не считается неисправностью при достаточном объёме доступной ОЗУ и отсутствии OOM;
- индекс не заменяет нагрузочное тестирование и аппаратную диагностику сервисным оборудованием.
