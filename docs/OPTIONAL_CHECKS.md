# Дополнительные проверки

`arm_info` автоматически выполняет безопасные read-only проверки, если соответствующие компоненты присутствуют:

- синхронизация времени (`timedatectl`, `chronyc`);
- признаки аварийного завершения предыдущей загрузки;
- Linux software RAID через `/proc/mdstat`;
- ECC/EDAC через `/sys/devices/system/edac`;
- состояние батареи через `/sys/class/power_supply`;
- последний SMART self-test;
- SSSD и список доменов;
- наличие Kerberos-билета в **текущем контексте запуска**;
- CUPS и количество очередей.

SSSD/Kerberos/CUPS не входят напрямую в базовый аппаратный индекс: они формируют контекст и рекомендации. Отсутствие Kerberos-билета при запуске от root не считается неисправностью пользовательской сессии.
