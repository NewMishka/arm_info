# Автоматизация

## Exit codes

| Код | Значение |
|---:|---|
| 0 | состояние нормальное и полнота проверки достаточна |
| 1 | есть предупреждения или неудовлетворительное состояние |
| 2 | критическое состояние |
| 3 | состояние нормальное, но диагностика неполная |
| 64 | ошибка параметров CLI |

## JSON

```bash
sudo arm_info --json --privacy --no-save
```

JSON содержит `schema_version`, системные показатели, scores, confidence, diagnostics и массив рекомендаций. Это предназначено для Ansible, мониторинга и последующей обработки.

Пример:

```bash
sudo arm_info --json --privacy --no-save | jq '.summary'
```
