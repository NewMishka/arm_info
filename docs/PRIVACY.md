# Приватность отчётов

По умолчанию технический отчёт предназначен для локальной административной работы и может содержать hostname, IP, MAC, DNS, gateway и имена SSSD-доменов.

Для отправки отчёта в публичный Issue используйте:

```bash
sudo arm_info --privacy
```

В режиме privacy:

- hostname заменяется на `ARM-REDACTED`;
- IPv4 сокращается до первых двух октетов (`10.20.x.x`);
- MAC заменяется на `xx:xx:xx:xx:xx:xx`;
- DNS и SSSD-домены скрываются;
- интерфейсы выводятся как `net1`, `net2`, ...;
- имя TXT/JSON файла не содержит hostname.

Режим не предназначен для формального анонимизирования любой произвольной команды из рекомендаций. Перед публикацией всё равно просмотрите отчёт.
