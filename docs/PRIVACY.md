# Приватность отчётов

По умолчанию технический отчёт предназначен для локальной административной работы и может содержать hostname, IP, MAC, DNS, gateway, доменные значения, пути сертификатов и имена SSSD-доменов.

Для отправки отчёта в публичный Issue используйте:

```bash
sudo arm_info --privacy
sudo arm_info --corp --privacy
```

В режиме privacy:

- hostname заменяется на `ARM-REDACTED`;
- IPv4 сокращается до первых двух октетов (`10.20.x.x`);
- MAC заменяется на `xx:xx:xx:xx:xx:xx`;
- DNS и SSSD-домены скрываются;
- интерфейсы выводятся как `net1`, `net2`, ...;
- enterprise-профили скрывают инфраструктурные значения и используют placeholders вроде `<DOMAIN>`, `<DC>`, `<MOUNT>`, `<QUEUE>`, `<CERT>` в диагностических командах там, где это необходимо;
- printer URI очищается от встроенных логина/пароля независимо от privacy-режима;
- автоматически сформированное имя TXT/JSON файла не содержит hostname.

Стандартное privacy-имя:

```text
ARM_INFO_PRIVATE_YYYY-MM-DD_HH-MM-SS.txt
```

Корпоративное privacy-имя:

```text
ARM_INFO_CORP_PRIVATE_YYYYMMDD_HHMMSS.txt
```

Режим не предназначен для формального анонимизирования любого произвольного текста, который может попасть в системный журнал или рекомендацию. Перед публикацией отчёт всё равно необходимо просмотреть.
