# Использование arm_info

## Рекомендуемый сценарий

1. Подключиться к АРМ по SSH.
2. Перейти в root: `su -` или использовать `sudo`.
3. Запустить файл: `bash arm_info.sh`.
4. Либо вставить весь текст `arm_info.sh` непосредственно в Bash-терминал.
5. После выполнения забрать созданный TXT-отчёт.

## Основные разделы отчёта

### СИСТЕМА

Показывает имя хоста, ОС, модель ПК, ядро, архитектуру, ориентировочную дату установки ОС, BIOS, наработку накопителей и uptime.

### ПРОЦЕССОР

Показывает модель, сокеты, физические ядра/потоки, Load Average и температуру CPU. Температура измеряется несколько раз; для оценки используется медианное значение, отдельно отображается максимум.

### ОПЕРАТИВНАЯ ПАМЯТЬ

Показывает тип/частоту, количество установленных модулей, общий и доступный объём, использование swap. OOM определяется по журналу ядра текущей загрузки.

### СЕТЬ

Для каждого активного IPv4-интерфейса выводятся IP, MAC и линк. Статистика RX/TX errors и dropped считается отдельно. Относительная доля выводится в ppm — количествах событий на миллион пакетов.

Например, `345 ppm` означает приблизительно 345 ошибок/дропов на 1 000 000 обработанных пакетов, а не 345 отдельных ошибок.

### НАКОПИТЕЛИ

Оптический привод определяется как `CD/DVD` и не участвует в оценке накопителей. HDD, SATA SSD и NVMe анализируются отдельно. При наличии `smartctl` считываются SMART, температура, наработка и показатели деградации.

### ФАЙЛОВЫЕ СИСТЕМЫ

Пример:

```text
Макс. заполнение          15% на /
Использование inode        3% на /
```

`inode` — служебные структуры файловой системы. При их исчерпании новые файлы нельзя создавать даже при наличии свободного места.

### СВОДКА СОСТОЯНИЯ

Показывает итоговый индекс по доступным данным и полноту проверки. Проценты в колонке «Вес в индексе» означают вклад группы в итоговый балл, а не процент износа.

### РЕКОМЕНДАЦИИ

Рекомендации выводятся только при наличии замечаний и содержат конкретное влияние, действие и команду для дальнейшей проверки.

## Получение последнего отчёта

```bash
ls -t ARM_INFO_*.txt | head -1
```

Просмотр:

```bash
less "$(ls -t ARM_INFO_*.txt | head -1)"
```
