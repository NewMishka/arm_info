# arm_info 1.2.4

Версия 1.2.4 посвящена качеству команд, которые `arm_info` предлагает администратору в рекомендациях.

## Что изменено

- проведена полная ревизия стандартных и корпоративных recommendation commands;
- исправлены некорректные варианты `nmcli` для DNS/802.1X;
- Kerberos-команды учитывают пользовательский credential-cache, а не предполагают только `/tmp/krb5cc_*`;
- DC TCP-проверки получили timeout;
- CUPS package diagnostics и software/RPM fallback исправлены;
- RAID больше не предполагает `/dev/md0`;
- динамические пути файловых систем shell-экранируются;
- несколько независимых команд стандартного отчёта выводятся отдельно, pipelines остаются цельными;
- `<...>` placeholders заменены безопасными именованными токенами;
- state-changing команды получают явное предупреждение;
- каждая команда имеет описание ожидаемого результата;
- добавлен постоянный CI-тест командного контракта и `docs/COMMANDS.md`.

Это pre-release ветка до полевого подтверждения на РЕД ОС; production release не должен публиковаться до отдельного решения.
