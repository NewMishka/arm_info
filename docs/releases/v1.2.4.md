# arm_info 1.2.4

Версия 1.2.4 посвящена качеству команд, которые `arm_info` предлагает администратору в рекомендациях, и усилению защиты отчёта от регрессов.

## Что изменено

- проведена полная ревизия стандартных и корпоративных recommendation commands;
- исправлены некорректные варианты `nmcli` для DNS/802.1X;
- Kerberos-команды учитывают пользовательский credential-cache, а не предполагают только `/tmp/krb5cc_*`;
- DC TCP-проверки получили timeout;
- CUPS package diagnostics и software/RPM fallback исправлены;
- RAID больше не предполагает `/dev/md0`;
- динамические пути файловых систем shell-экранируются;
- несколько независимых команд стандартного отчёта выводятся отдельно, pipelines остаются цельными;
- `<...>` placeholders заменены безопасными именованными токенами;
- state-changing команды получают явное предупреждение;
- каждая команда имеет описание ожидаемого результата;
- CIFS-рекомендация больше не требует вручную подставлять путь: она автоматически получает локальные `TARGET` через `findmnt -n -l -t cifs -o TARGET`, без `-r/--raw`, поэтому кириллица не превращается в `\xd0...`; TARGET читается одной колонкой без `awk`, поэтому пробелы в имени не создают ложный WARN; доступность проверяется фактическим минимальным чтением каталога через `find -print -quit` с timeout вместо metadata-only `stat -f`;
- добавлен постоянный CI-тест командного контракта и `docs/COMMANDS.md`;
- во время полевого pre-release теста обнаружена и устранена регрессия SMART: восстановлен helper `run_smart()`, без которого системный NVMe/SSD мог отображаться с `SMART Н/Д`, без ресурса, температуры и наработки;
- в базовый CLI test добавлен отдельный guard, проверяющий наличие `run_smart()`, timeout-контракт и использование helper при чтении SMART;
- добавлен `tests/test_sections.sh`: он проверяет все пользовательские разделы стандартного TXT, основные группы standard JSON, все секции `domain/network/print/software/enterprise` и корпоративный TXT;
- аппаратно-зависимые пути SMART/CPU/ФС защищены отдельными regression guards, чтобы удаление критичного helper не проходило CI незаметно;
- найдено и исправлено оставшееся старое название `Стабильность ОС` в сводной таблице: во всём пользовательском отчёте используется единое `Стабильность системы`.
