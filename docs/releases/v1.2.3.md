# arm_info 1.2.3

Версия 1.2.3 исправляет оценку накопителей при подключённых USB/съёмных носителях и делает системный диск приоритетным.

## Что изменено

- оценка стабильности переименована в `Стабильность системы`: в отчёте показываются `100/100`, каждый учитываемый сигнал и его штраф; формула/пороги не менялись, изменена прозрачность представления;
- исправлена полевая ошибка: имя системного диска очищается от tree-префикса `lsblk`, поэтому root-диск не может ошибочно стать `Дополнительный`;
- оптические устройства явно выводятся `вне индекса`;
- 802.1X больше не ограничивается только активными NM-профилями: проверяются все настроенные профили и host-named certificate fallback в `/etc/pki/tls`;
- физический диск корневой ФС определяется через `findmnt` + `lsblk -s`, включая типовой LVM/device-mapper;
- системный диск выводится первым с ролью `Системный`;
- USB/съёмные носители имеют роль `Съёмный (вне индекса)` и тип `USB-накопитель`/`Съёмный накопитель`;
- removable media не влияют на storage score, SMART completeness, эксплуатационный возраст и SMART-рекомендации;
- файловые системы съёмных носителей не участвуют в `Макс. заполнение`, inode-score и read-only штрафах;
- системный накопитель имеет 80% веса внутри storage-группы, худший известный дополнительный внутренний — 20%;
- если физический системный диск определить не удалось, сохраняется fallback по внутренним несъёмным накопителям;
- JSON storage содержит отдельные счётчики системных, дополнительных и съёмных накопителей;
- стандартный блок рекомендаций использует такое же выравнивание полей и команд, как корпоративный;
- команды в рекомендациях выводятся одной физической строкой без принудительного `fold`; длинная команда может визуально переноситься терминалом, но при копировании остаётся цельной; пояснение к команде выводится отдельной строкой в скобках;
- корпоративная шапка отображается как `ARM_INFO КОРПОРАТИВНЫЙ`; внутренний ключ профиля `enterprise` и JSON schema v2 сохранены для совместимости;
- 802.1X показывает сертификаты из основного и phase2 профиля, поддерживает PEM/DER и выводит Subject/Issuer, даты начала/окончания и остаток срока; `nmcli` запрашивается без escape для корректной обработки `file://`;
- JSON stability дополнен факторами и штрафами, чтобы расчёт можно было объяснить программно.

Цель изменения: подключённая флешка не должна ухудшать оценку технического состояния АРМ, снижать полноту SMART или подменять показатели системного диска/файловой системы.

## Полевое подтверждение

На целевом РЕД ОС подтверждено:

- системный NVMe корректно определяется как `Системный`;
- USB-флешка отображается как `Съёмный (вне индекса)` и не влияет на итоговый индекс;
- оптический привод отображается как `Оптический (вне индекса)`;
- блок 802.1X отображает профиль/сертификат и даты действия корректно.

Перед релизом остаётся повторно проверить на реальном АРМ новый прозрачный блок `СТАБИЛЬНОСТЬ СИСТЕМЫ` и копирование длинных команд из рекомендаций.

Production Release, когда версия будет подтверждена и смёржена в `main`, должен содержать single-file `arm_info.sh` и `SHA256SUMS`. Проверка скачанного скрипта:

```bash
sha256sum -c SHA256SUMS
```
