# arm_info 1.2.0

Enterprise diagnostics release.

- `--profile domain`: AD/SSSD/Kerberos, `adcli testjoin`, Kerberos tickets, time sync, DNS SRV and KDC/LDAP reachability;
- `--profile network`: DNS/upstream, interfaces, 802.1X certificate lifetime, CIFS/GVFS/Caja;
- `--profile print`: CUPS service/scheduler, queues, jobs, backend URI and journal warnings/errors;
- `--profile software`: R7, Citrix/ICAClient, Remmina/FreeRDP, browsers, Basis Workplace, Crypto/Token middleware and SNX inventory;
- `--profile enterprise`: combined enterprise profile;
- `--compare`: compare two JSON reports from working/problem workstations;
- enterprise JSON schema v2 and expanded privacy mode;
- CI tests, installer and RPM packaging updated for the enterprise helper.

Enterprise checks are read-only and do not change AD, NetworkManager, CUPS, Kerberos or application configuration.
