# arm_info 1.2.0

Предрелизная версия. Публикация релиза выполняется только после успешного CI и runtime-проверки на реальных РЕД ОС 7/8.

- `--profile domain`: AD/SSSD/Kerberos, `adcli testjoin`, Kerberos tickets, ошибки Kerberos, синхронизация времени, DNS SRV и доступность KDC/LDAP;
- `--profile network`: DNS/upstream, интерфейсы, 802.1X и сроки сертификатов, CIFS/GVFS/Caja;
- `--profile print`: CUPS service/scheduler, очереди, задания, backend URI и журнал;
- `--profile software`: глобальная инвентаризация всех установленных RPM-пакетов без списка заранее заданных приложений;
- `--profile enterprise`: `domain + network + print`, без объёмной программной инвентаризации;
- `--compare`: сравнение двух JSON-отчётов рабочих станций;
- enterprise JSON schema v2 и расширенный privacy mode;
- подробные рекомендации для `WARN/CRIT/N/A`: возможные причины, влияние, что проверить, действия, команды и контроль результата;
- CI, installer и RPM packaging обновлены для enterprise helper.

Enterprise-проверки read-only и не изменяют AD, NetworkManager, CUPS, Kerberos или конфигурацию приложений. Команды, способные изменить состояние, показываются только как рекомендации с явным контекстом и не выполняются автоматически.
