# arm_info 1.1.0

Public-readiness release.

- CLI: `--help`, `--version`, `--privacy`, `--no-save`, `--output`, `--quiet`, `--json`, `--config`;
- стабильные exit codes для автоматизации;
- JSON schema v1;
- безопасное чтение `/etc/arm_info.conf` и настраиваемые пороги;
- privacy mode для публичных отчётов;
- дополнительные проверки времени, software RAID, ECC/EDAC, батареи, SMART self-test, SSSD/Kerberos/CUPS;
- install script, Makefile и RPM spec;
- CI, issue templates, contribution/security docs;
- документированная матрица совместимости.
