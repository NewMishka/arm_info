# arm_info 1.2.2

Улучшение читаемости стандартной и корпоративной диагностики, блока 802.1X и сохранения отчётов.

- корпоративный TXT-отчёт получил выровненные колонки `Параметр / Статус / Значение`;
- длинные строки и рекомендации переносятся по ширине терминала;
- `--corp` по умолчанию сохраняет TXT/JSON-отчёт в текущий каталог; `--no-save` отключает сохранение;
- при `--privacy` автоматическое имя корпоративного отчёта не содержит hostname;
- стандартный отчёт получил выровненные рекомендации с аккуратным переносом длинных строк;
- команды в рекомендациях стандартного и корпоративного отчётов снабжены пояснением в скобках, что именно даст команда;
- корпоративные рекомендации сохраняют shell pipeline и `|` внутри регулярных выражений как части одной команды, а не разбивают их на отдельные строки-команды;
- температура CPU в стандартном отчёте отображается как `${CPU_TEMP}°C (медиана)` без одновременного вывода максимума;
- блок 802.1X показывает активный профиль, EAP, пути client/CA certificates, даты действия и остаток срока;
- в блоке 802.1X выводится готовая проверка `openssl x509 -in "<CERT>" -noout -dates`;
- интерактивный `--corp` очищает экран перед TXT-выводом;
- JSON не получает escape/control sequences и остаётся пригодным для автоматизации;
- глобальная инвентаризация ПО по-прежнему запускается только отдельно через `--profile software`.

Практический запуск:

```bash
sudo bash /tmp/arm_info.sh --corp
```

При таком запуске TXT-отчёт сохраняется автоматически в текущий каталог с именем вида `ARM_INFO_CORP_<HOST>_<DATE>.txt`. В privacy-режиме hostname из автоматического имени исключается. Отключить сохранение можно через `--no-save`.

Обезличенный JSON с фиксированным путём:

```bash
sudo bash /tmp/arm_info.sh --corp --privacy --json -o /tmp/arm-corp.json
```
