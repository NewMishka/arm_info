# arm_info 1.2.1

Однофайловая поставка для удалённой диагностики АРМ.

- `arm_info.sh` содержит базовую и enterprise-диагностику;
- встроены профили `domain`, `network`, `print`, `software`, `enterprise`;
- встроен `--compare`;
- внешний `arm_info-enterprise.sh` и `libexec` больше не требуются;
- installer/RPM/CI переведены на один исполняемый файл.

Типовой запуск по SSH:

```bash
scp arm_info.sh admin@HOST:/tmp/
ssh admin@HOST
sudo bash /tmp/arm_info.sh --profile enterprise
```
