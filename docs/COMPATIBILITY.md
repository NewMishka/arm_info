# Совместимость

| Система | Статус |
|---|---|
| РЕД ОС 7.x | основная целевая платформа |
| РЕД ОС 8.x | основная целевая платформа |
| RHEL / Rocky / AlmaLinux / CentOS | совместимая RHEL-семья; требуется полевое тестирование конкретной конфигурации |
| Fedora | совместимая; Bash syntax и RPM build проверяются CI |
| Ubuntu 24.04 | экспериментальная; Bash syntax проверяется CI |
| Debian / другие Ubuntu | экспериментальная |
| прочие Linux | best effort |

Скрипт использует стандартные Linux-интерфейсы `/proc`, `/sys`, `findmnt`, `df`, `ip`, `systemctl` и опциональные `smartctl`, `dmidecode`, `sensors`. Enterprise-профили дополнительно используют доступные в системе `NetworkManager/nmcli`, `realm`, `sssctl`, `adcli`, `klist`, DNS tools, `openssl`, CIFS/GVFS/GIO и CUPS.

CI выполняет Bash syntax checks в Ubuntu 24.04, Fedora и Rocky Linux 9, а также installer/RPM smoke tests. Эти проверки подтверждают синтаксис, тестовые контракты и упаковку, но не равны runtime-сертификации дистрибутива.

РЕД ОС 7/8 остаётся основной полевой платформой. Поведение отдельных проверок зависит от фактического набора пакетов, версии ядра, драйверов, systemd/NetworkManager и корпоративной инфраструктуры.

Не все платформы публикуют температуры, DMI, EDAC/ECC и vendor-specific SMART одинаково. Недоступный показатель должен снижать полноту диагностики, а не подменяться значением `100/100`.

## Накопители и съёмные носители

В 1.2.3 системный физический диск определяется по цепочке корневой ФС через `findmnt`/`lsblk -s`, включая типовой LVM/device-mapper. Признак съёмности берётся из `/sys/class/block/<dev>/removable` и transport `lsblk -o TRAN`; для типовых автомонтирований `/run/media`/`/media` используется fallback. Системный диск никогда не исключается из оценки только из-за transport/removable-флага (например, при загрузке ОС с внешнего носителя).
