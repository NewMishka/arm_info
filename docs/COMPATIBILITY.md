# Совместимость

| Система | Статус |
|---|---|
| РЕД ОС 7.x | основная поддержка |
| РЕД ОС 8.x | основная поддержка |
| RHEL / Rocky / AlmaLinux / CentOS | совместимая, требуется полевое тестирование |
| Fedora | совместимая |
| Debian / Ubuntu | экспериментальная |
| прочие Linux | best effort |

Скрипт использует стандартные Linux-интерфейсы `/proc`, `/sys`, `findmnt`, `df`, `ip`, `systemctl` и опциональные `smartctl`, `dmidecode`, `sensors`.

Не все платформы публикуют температуры, DMI, EDAC/ECC и vendor-specific SMART одинаково. Недоступный показатель должен снижать полноту диагностики, а не подменяться значением `100/100`.
